# Scoop Bucket for WorkBuddy助手

This bucket distributes the Windows release of [WorkBuddy助手](https://github.com/deloz/workbuddy-assistant).

## Install

```powershell
scoop bucket add workbuddy-assistant https://github.com/deloz/scoop-workbuddy-assistant
scoop install workbuddy-assistant
```

## Update

```powershell
scoop update workbuddy-assistant
```

## Uninstall

```powershell
scoop uninstall workbuddy-assistant
```

The manifest is updated automatically after a new GitHub Release is published.
